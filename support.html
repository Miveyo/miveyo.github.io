DNS Browser Support

Help topics and troubleshooting information preserved from the original support page.

Legacy DNS Browser 2.0 system requirements

The original support page listed the following minimum requirements for older DNS Browser builds:

  • Operating system: Windows Vista, Windows 7, Windows 8.x or Windows 10. DNS Browser 2.0 also listed Windows 11 support.
  • RAM: 1 GB.
  • CPU: 1 GHz dual-core processor.
  • GPU: Dedicated graphics not required.
These are archived requirements from the old DNS Browser support page, not verified requirements for DNS Browser 3.0.

Fix older versions crashing

to fix crashing issue try installing .NET Framework 4.6.1 for DNS Browser 1.0, 1.5 and 2.0 beta, then restarting the computer.

Change the browser background image

You can simply change background image of browser UI by going to settings page then in Themes tab select background you like

Check for updates

Open Settings, find the Update tab and select “Check for updates”.
