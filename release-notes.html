DNS Browser Dev release notes

Release history from the DNS Browser 2.5 development cycle, retained from the published Miveyo Google Sites copy.

DNS Browser 2.5 · 2025

Version 2.5.10 · October 2025

  • Added “Browser Mode” in the Advanced tab in Settings.
  • Improved browser performance.
  • Updated the Chromium browser engine.

Version 2.5.09 · September 2025

  • New Password Manager for DNS Browser.
  • Added Cloud Sync option.
  • Updated Microbridbox Security Database.
  • Added Picture-in-Picture mode.
  • Fixed fullscreen mode issues.
  • Improved browser performance.
  • Updated the Chromium browser engine.

Version 2.5.08 · August 2025

  • Added H.264 codec support.
  • Added a new search bar in Settings.
  • Added favicon icons on tabs instead of the address bar only.
  • Introduced the new AdBlock implementation powered by uBlock.
  • Improved browser performance and UI.
  • Updated the Chromium browser engine.

Version 2.5.07 · July 2025

  • Updated DNS Browser Dev logo.
  • Added Browser Data Sync.
  • Updated the Chromium browser engine.

Version 2.5.06 · June 2025

  • Fixed an issue where the browser crashed when opening eight tabs and closing the first tab.
  • Updated the Chromium browser engine.
  • Additional small fixes and performance improvements.

DNS Browser 2.5 Dev · First release

The original page introduced monthly browser updates for the Dev channel.

This is a historical changelog for version 2.5. It does not describe the feature set or release status of DNS Browser 3.0.
