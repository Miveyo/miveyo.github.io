Quatnum OS

Experimental project

A different desktop experience.

Quatnum is a Windows gaming launcher designed to bring your game library and frequently used system controls together in one convenient interface. Browse your games, launch supported titles, and access essential settings through a gaming-focused experience.

Quatnum is an application for Windows, not a standalone operating system or a replacement for Windows. Its features and availability may change as the project evolves.

Designed around gaming

Quatnum brings together several everyday gaming tasks, reducing the need to navigate through multiple Windows menus and applications.

Game Library

Browse your detected games from a centralized library. Keep your installed titles accessible through a dedicated gaming interface.

Game Launching

Launch supported games directly from Quatnum. Games that rely on external platforms can continue using their respective launchers.

Quick Settings

Access frequently used system controls through the Quatnum action center, including Wi-Fi, Bluetooth, sound, and display settings.

Gaming-focused navigation

Navigate through a simplified interface designed with gaming controls in mind, while retaining the familiarity of a Windows application.

See Quatnum in action

Take a closer look at the interface, quick settings, and game-launching experience.

About the project

Quatnum is an experimental Miveyo project exploring a more convenient way to access games and everyday system controls on Windows. It is intended to provide a gaming-oriented interface without requiring users to replace their existing operating system.

Project status: Experimental. Public availability and future development plans may change.
