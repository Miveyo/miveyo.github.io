# Miveyo Website — GitHub Pages package

This is a static HTML/CSS/JavaScript rebuild based on the **PUBLISHED** section of the Miveyo Google Sites export.

## Publish
1. Extract the ZIP.
2. Open the `Miveyo/miveyo.github.io` repository on GitHub.
3. Choose **Add file → Upload files**.
4. Upload all files and folders from this package to the repository root (not the outer ZIP folder).
5. Commit the upload to `main`.
6. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`.
7. Open https://miveyo.github.io after the Pages deployment completes.

## Notes
- The old Google Sites copy includes a `DRAFT` folder and a `PUBLISHED` folder. This package uses the published page content as the primary source.
- Product copy and historical release information were adapted from the export. The archived 2.x download links are labeled as legacy.
- DNS Browser 3.0 is marked as in development; no 3.0 download is advertised.
- Embedded YouTube and Google Drive videos use their original embed IDs/links. Their availability depends on the original sharing permissions.
- Some original screenshots and banners contain former Microbridbox-era branding because the export did not contain updated Miveyo replacements.
